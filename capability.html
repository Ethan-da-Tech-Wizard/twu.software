Differentiators

Offline by default, online by choice

TWU's own tools run offline by default and go online only when the customer wants a feature that needs it.

tiny_dancer (prototype): a 20B-parameter model on a laptop GPU

tiny_dancer is a fully offline agent built on the open-weight GPT-OSS-20B model (about 20 billion parameters). It runs on a laptop with an RTX 3070 Laptop GPU with 8 GB of VRAM. The model does not fit in 8 GB of VRAM, so the first 16 expert layers run on the CPU and the remaining expert and dense layers run on the GPU.

tiny_dancer: current status, stated plainly

The project README records 617 harness and comparison regression checks passing, and that full native qualification has not passed: a larger inventory task and an exact-money repair still fail. It is a prototype, not a delivered product.

Verify before done

The same verification habit is applied to AI output: a task is not marked done until real tests pass, and the proposed document tools are designed to show the exact source passage and page for each answer and to say so when support cannot be confirmed.

Deterministic claim verification gate

Written claims in company documents that leave the building are registered with their exact text and checked by a deterministic script against company records, with no model calls and no network. The same mechanism checks the statements on this page.

Traceable local AI work

Karl, TWU's offline LLM lab, records a JSONL trace of every generation and supports local search over PDFs, Word files, code and CSV, per its project README.

Open-source policy

Company policy recorded 2026-11-05: TWU's own software is to be released as open source under GPL-3.0-or-later. Existing public repositories carry their own licenses (Apache-2.0, MIT, AGPL-3.0).
